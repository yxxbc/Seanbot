# 知识库说明

> 设计/实现说明，随仓库发布；使用层面的说明见知识库条目 `SeanbotTools/02-KnowledgeBase.md`。

## 内置知识库
在 Seanbot 项目中的 kb目录下的内容均为内置官方知识库
其知识库采用远程最新文件内容来判断是否为最新，以及是否需要更新

## 外置知识库
外置知识库是指用户在使用Seanbot中使用其agent创建了知识库，或者用户自身创建了知识库，统一归类为外置知识库

# 二者之间
内置知识库与外置知识库应该被识别，防止agent或者用户失误将其卸载或者损坏。
二者之间的文件实际路径应该也不同。

# 实现（已落地）

## 目录

| | 默认路径 | 说明 |
|---|---|---|
| 内置 | `~/.seanbot/kb` | 随二进制分发，首次使用时自动释放；官方维护，**只读** |
| 外置 | `~/.seanbot/kb-custom` | 用户与 agent 自建，可写 |

两个目录都在数据目录下，路径不同；工具输出里用 `[内置]` / `[外置]` 标出来源。

## 工具与命令

- `kb_list` 列出条目；`kb_search` 按正则搜内容；`read` 看全文
- `kb_add` / `kb_edit` 维护外置条目（`kb_edit` 与 `edit` 共用同一套替换引擎）
- `kb_update` 等价于 `sean kb update`：取回远程索引与条目，只覆盖有变化的文件，并清理远程已删除的条目
- CLI：`sean kb`（列出）与 `sean kb update`（更新）

## 远程更新

- 索引：仓库 `kb/index.json`，列出全部条目路径；每个知识库目录里也存一份 `index.json`，记录最近一次应用成功的清单
- 地址：默认 `https://raw.githubusercontent.com/yxxbc/Seanbot/main/kb`，可用 `SEANBOT_KB_BASE_URL` 或配置 `[tools.kb] base_url` 覆盖
- 判断"是否最新"：逐条比较远程内容与本地内容，一致就跳过——不依赖版本号，也不需要额外维护哈希

## 防止误删误改

- 内置目录受保护：`edit` 拒绝写入、`bash` 命中路径写法时直接拒绝（护栏，不是沙箱）
- 外置目录不设保护，用户可以直接编辑文件
- 释放内置条目时只补缺失文件，不覆盖已存在的，避免把远程更新过的内容顶回旧版
