# 内核

> 设计/实现说明，随仓库发布；代码是权威来源。

内核只负责这些事情：
1. 目标与任务状态
    
    - 当前总目标
    - 子任务列表
    - 已完成、进行中、失败的任务
    - 优先级、截止时间和成功标准
2. 当前上下文
    
    - 最近的对话或事件
    - 当前环境状态
    - 用户约束与偏好
    - 正在执行的步骤
    - 重要事实和中间结论
3. 决策与执行循环
    
    - 感知：获取输入、环境变化和工具结果
    - 思考：分析现状、选择下一步
    - 行动：调用工具或执行任务
    - 观察：检查行动结果
    - 修正：失败重试、调整计划或请求帮助
 4. 工具注册
	 
	 - 内置工具：确保不可更改，除非版本更新
	 - Seanbot自己创建的：确保可以注册到内核中从而可以被agent调用
	 - 插件系统注册：外部插件的下载后，确保可以正确的注册
