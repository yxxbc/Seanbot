# 工具说明

> 清单以源码 `crates/seanbot-core/src/tools/` 与知识库条目 `SeanbotTools/` 为准；标「规划中」的都还没实现。
> 每个工具都声明风险等级：**只读**工具直接执行，**改动**工具在确认模式下要先请用户点头（`-p` 非交互时默认拒绝）。

## 内置工具（16 个，工具名就是调用名）

### 文件与命令
| 工具 | 作用 | 风险 |
|---|---|---|
| `read` | 读文件（带行号）；记录内容指纹，供 `edit` 校验 | 只读 |
| `edit` | 改文件或新建文件；要求先 `read` 且内容未被外部改动 | 改动 |
| `search` | 按 glob / 正则搜文件名与内容，自动遵守 `.gitignore` | 只读 |
| `bash` | 执行命令（默认 120 秒超时，超时杀整个进程组）；带 `session` 参数时进常驻会话 | 改动 |

### 感知与联网
| 工具 | 作用 | 风险 |
|---|---|---|
| `perceive` | 当前时间、模型、权限模式、会话文件、工作目录、git 状态、本轮累计用量 | 只读 |
| `web_search` / `web_fetch` | 联网搜索与取网页正文（默认 AnySearch 后端，未配 key 走匿名） | 只读 |

### 知识库
| 工具 | 作用 | 风险 |
|---|---|---|
| `kb_list` / `kb_search` | 列条目、按正则搜内容（内置 + 外置） | 只读 |
| `kb_add` / `kb_edit` | 维护**外置**知识库（内置只读，改不了） | 改动 |
| `kb_update` | 从官方地址同步内置知识库（与 `sean kb update` 同一段逻辑） | 改动 |

### 技能
| 工具 | 作用 | 风险 |
|---|---|---|
| `skill` | 不带参数列可用技能；带名字加载该技能正文 | 只读 |
| `create_skill` | 按官方标准脚手架一个**外置**技能（内置技能只读） | 改动 |

### 会话与配置
| 工具 | 作用 | 风险 |
|---|---|---|
| `bash_session` | `list` / `close` / `close_all` 常驻 bash 会话 | 改动（`list` 只读） |
| `config` | `list` / `get` / `set` / `unset` 白名单内的配置键（见 [配置.md](配置.md)） | 改动（`list` / `get` 只读） |

## 规划中
