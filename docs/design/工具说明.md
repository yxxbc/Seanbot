# 工具说明

> 这里给的是工具的**分层规划**（已实现 / 规划中）。完整且最新的工具清单以源码 `crates/seanbot-core/src/tools/`
> 与知识库条目 `SeanbotTools/` 为准；标「规划中」的都还没实现。

### 内核层基础工具
- read   读取文件 （agent）
- edit   修改文件 （agent）
- bash   执行命令 （agent）
- search 搜索代码和文件 （agent）

### 中间层工具
#### 知识库工具（已实现）
- kb_edit 修改非内置知识库内容
- kb_list 列出所有知识库
- kb_add 向非内置知识库添加内容
- kb_search 搜索知识库里面的内容
- kb_update 更新内置知识库（内核里直接调用与 `sean kb update` 同一段逻辑，不另起进程）
#### 人格工具（规划中）
- per_add 创建人格、人格头像、人格别名、人格专属独立路径 （agent、用户）
- per_edit 修改人格、人格头像、人格别名 （agent、用户）
- per_list 列出所有非内置的人格详情 （agent、用户）
- per_search_seesion 搜索当前人格的某个会话记录（用户）
- per_edit_seesion_headline 更改当前人格的某个会话的标题 （agent、用户）
- per_seach_memory 搜索当前人格记忆 （agent、用户）
