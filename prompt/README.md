# 系统提示词模板

这些文件是 **Seanbot 系统提示词的正文**，通过 `include_str!` 在编译期内嵌进二进制
（见 `crates/seanbot-core/src/prompt.rs`）。放在这里是为了让改提示词只动 markdown，不用碰 Rust。

| 文件 | 内容 |
| --- | --- |
| `identity.md` | 身份、关于你自己（数据目录、命令、权限） |
| `environment.md` | 环境（工作目录、主目录、系统、解释器、日期） |
| `workflow.md` | 工作方式（编辑约定、联网、知识库、技能、安全边界） |

按这个顺序拼接，中间空一行。后面还会由代码追加两个动态小节：
「# 项目指令」（AGENTS.md / CLAUDE.md 的内容）与「# 可用技能」（技能清单）。

## 占位符

用 `{{名字}}` 表示运行期才确定的值，目前有：

`{{version}}` `{{data_dir}}` `{{cwd}}` `{{home}}` `{{os}}` `{{shell}}` `{{date}}`

没被替换的占位符会被原样保留——有测试（`prompt::tests::every_placeholder_is_substituted`）兜住这种情况。

## 注意

- 改完必须**重新编译**才生效（提示词是编译期内嵌的）。
- 这里写的是**静态文本**，不要引入会变化的内容（模型名、当前时间、权限模式等），
  否则会话内系统提示词会变，DeepSeek 前缀缓存整段失效——这类信息由 `perceive` 工具提供。
- 提示词是会话开始时生成一次的：改了它，**已经开始的会话不会变**，新会话才生效。
