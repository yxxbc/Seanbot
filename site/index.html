它到底能做什么

不只是聊天，它能动手

Seanbot 把工具调用串成一条链路：先看现状，再动手改，改完自己验证。 每一步都在你的终端里可见、可打断、可拒绝。

看完整说明
  1. 01

    八个内置工具

    read edit bash search perceive web_search web_fetch config——读改跑查一条龙，命令受黑名单约束，上限与配置交给 config。

  2. 02

    会话随时接着聊

    sean -c 继续上一次，sean -r 从列表里挑。历史逐条落盘，恢复后前缀缓存照旧命中。

  3. 03

    改动前先问你

    确认模式下 edit 与 bash 逐次征求许可，也能一键 YOLO；黑名单在任何模式下都生效。

  4. 04

    中文优先

    界面、提示词、报错都是中文；命令与工具名保持英文，方便和文档对照。

  5. 05

    自己升级自己

    sean update 查最新版、下载对应平台的包、校验 SHA256 后原地替换。

  6. 06

    换厂商只是加一条描述

    厂商层数据驱动，内置 DeepSeek；任何 OpenAI 兼容服务加一条描述即可接入。
