Not a chatbot

不是聊天窗口。
是一个可以工作的 Agent。

Seanbot 把模型、工具、权限和项目上下文串成一条链路。你只说目标， 剩下的由它自己决定读什么、改什么、跑什么，以及什么时候停下来问你。

Agent loop

从一句话，到事情完成

每一次行动都经过同一套循环：工具不是散落在界面里的命令， 而是它随时可以调用、也能被你拦下的能力。

  1. 01

    理解

    读懂目标，并自动带上项目指令（AGENTS.md / CLAUDE.md，越靠近工作目录越优先）。

    →
  2. 02

    读取

    read 读文件、search 搜代码、kb_search 查它自带的知识库。

    →
  3. 03

    行动

    edit 改文件、bash 跑命令；要联网就 web_search / web_fetch。

    →
  4. 04

    验证

    跑测试、看输出；结果不对就回到上一步重来，而不是把问题留给你。

    →
  5. 05

    完成

    汇总改了什么、结果如何，把结论和改动一起交回你手上。

它到底能做什么

不只是聊天，它能动手

Seanbot 把工具调用串成一条链路：先看现状，再动手改，改完自己验证。 每一步都在你的终端里可见、可打断、可拒绝。

看完整说明
  1. 01TOOLS

    工具箱够用

    内核 read edit bash search perceive；联网 web_search web_fetch；知识库 kb_*；技能 skill；上限与默认值交给 config。命令受黑名单约束，上限写在 config.toml 里随时可调。

  2. 02SESSION

    会话随时接着聊

    sean -c 继续上一次，sean -r 从列表里挑。历史逐条落盘，恢复后前缀缓存照旧命中。

  3. 03PERMISSION

    改动前先问你

    确认模式下改动类工具逐次征求许可（edit、bash，以及 config 的 set/unset），也能一键 YOLO；黑名单在任何模式下都生效。

  4. 04I18N

    中文优先

    界面、提示词、报错都是中文；命令与工具名保持英文，方便和文档对照。

  5. 05UPDATE

    自己升级自己

    sean update 查最新版、下载对应平台的包、校验 SHA256 后原地替换（Windows 重跑安装命令）；不用回官网手动下载。

  6. 06PROVIDER

    换厂商只是加一条描述

    厂商层数据驱动，内置 DeepSeek；任何 OpenAI 兼容服务加一条描述即可接入。

  7. 07CONTEXT

    懂你的项目

    会话开始自动注入项目指令（AGENTS.md / CLAUDE.md，从全局到工作目录逐级取，越近的越优先）；走到子目录再按需补该目录的约定。技能放 .seanbot/skills/，只在需要时读全文，不占常驻上下文。

  8. 08KB

    自带知识库

    官方知识库随二进制分发、只读；外置知识库可写。Sean 用 kb_search 查自己的文档、用 kb_add 记长期事实；你也能 sean kb 看条目、sean kb update 拉最新。

项目状态

三样东西，进度不一样

可用CLI

单轮入口：sean -p "问题" 输出答案就退出，适合脚本与 CI；重定向到文件时输出原始 Markdown。五个构建目标（macOS / Linux / Windows）都能装，sean update 一键升级。

可用TUI

默认界面：行内 TUI（ratatui）。助手回复流式 Markdown 写进终端滚动区，/ 弹出命令浮窗，改动类工具有确认框，Ctrl+O 打开转录视图，还有吉祥物"环环"。与 CLI 同一个 sean，装完直接用。
